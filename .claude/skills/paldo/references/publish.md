# PALDO publishing pack: templates (penicillin example)

Give each item as its own code block so the user can copy it.

**Title**: the video title + one emoji.
```
The Messy Desk That Saved Millions 🧫
```

**Long description (YouTube)**: hook line → 2 short paragraphs retelling the story with year, place and names → the twist → 📚 a facts line with dates and a caveat where accounts differ → 🎬 an "Original animated short" note → 🎙️ "Voiceover generated with ElevenLabs." → 3–4 hashtags.

**Short caption (Shorts / TikTok / Reels)**: one line with the hook and the payoff, plus an emoji and 4–5 hashtags.

**YouTube tags**: 20–28 comma-separated tags. Cover:
- the main subject and the people in it
- "history of X" and "how X was discovered"
- the era and year
- the key objects
- related institutions
- genre tags: animated history, cartoon history, history shorts, science shorts, fun facts, did you know, educational animation
- the theme, e.g. accidental discovery or lucky accidents in history

**Hashtags (TikTok / Reels)**: 12–15 hashtags, e.g. #history #science #<topic> #<person> #historyfacts #didyouknow #funfacts #animation #cartoon #shorts #edutok #learnontiktok

**Upload tips** (one short paragraph in Tagalog):
- "Not made for kids" unless the user is sure of the audience.
- Turn on "Altered or synthetic content" (AI voice).
- Free ElevenLabs plan: no commercial use; keep the attribution.
