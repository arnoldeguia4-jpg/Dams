# LUGAR publishing pack: templates

Give each item as its own code block and save the pack as `out/publish.md`.

**Title**: the hook in Tagalog/Taglish + 1–2 emoji (≤ 70 characters), e.g. `Sa Barangay Namin, Binabayaran ang Pagkakamali 💸`.

**Long description (YouTube)**: the hook line → 2 short paragraphs retelling the story without spoiling the twist ("Pero may isang bagay na hindi namin inaasahan…") → "Panoorin hanggang dulo 👀" → 🎬 "Original animated short" → 🎙️ "Voiceover generated with ElevenLabs." → 3–4 hashtags.

**Short caption (Shorts / TikTok / Reels)**: one teaser line + "abangan ang ending" style hook + 4–5 hashtags.

**YouTube tags**: 15–25 phrases, ≤ 500 characters total: the premise in Tagalog and English, "kwentong pinoy", "pinoy animation", "roblox style animation", "tagalog story", "twist ending", "funny pinoy story", the setting (barangay, palengke, eskwela…), the theme. Offer the one-word-per-tag list too if the user prefers it.

**Hashtags**: 12–15, e.g. #kwentongpinoy #pinoyanimation #tagalogstory #twistending #roblox #animation #storytime #pinoy #funny #shorts #fyp

**Upload tips** (Tagalog): "Not made for kids" unless sure; turn on "Altered or synthetic content" (AI voice); ElevenLabs Starter plan allows commercial use, keep the credit.
