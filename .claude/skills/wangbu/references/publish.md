# WANGBU publishing pack: templates

Give each item as its own code block so the user can copy it, and save the whole pack as `out/publish.md`.

**Title**: the why question + one emoji.
```
Why Are Stop Signs Red? 🛑
```

**Long description (YouTube)**: the question as the first line → 2 short paragraphs with the answer (year, place, names, the cause and effect) → the "That's why…" line → 📚 a facts line with dates and a caveat where accounts differ → 📚 sources → 🎬 "Original animated short" note → 🎙️ "Voiceover generated with ElevenLabs." → 3–4 hashtags.

**Short caption (Shorts / TikTok / Reels)**: the question + a one-line teaser, an emoji and 4–5 hashtags.

**YouTube tags**: 20–28 comma-separated tags. Cover:
- the question in several phrasings ("why are stop signs red", "stop sign color reason", "why stop signs red not yellow")
- the subject, the people, places and years in the answer
- "history of X", "how X started", "the reason X"
- genre tags: why explained, that's why, fun facts, did you know, explained in 60 seconds, animated explainer, educational animation, cartoon facts, shorts
- the field, e.g. science facts, history facts, animal facts

**Hashtags (TikTok / Reels)**: 12–15, e.g. #why #thatswhy #funfacts #didyouknow #explained #<topic> #<field>facts #learnontiktok #edutok #animation #cartoon #shorts

**Upload tips** (one short paragraph in Tagalog):
- "Not made for kids" unless the user is sure of the audience.
- Turn on "Altered or synthetic content" (AI voice).
- ElevenLabs Starter plan: commercial use is allowed; keep the attribution.
