# PALDONT publishing pack: templates (myth / alamat)

Give each item as its own code block so the user can copy it.

**Title**: the video title + one emoji.
```
The Girl Who Became a Pineapple 🍍
```

**Long description (YouTube)**: hook line → 2 short paragraphs retelling the myth (where it's told, who the characters are) → the twist / "and that's why…" → 📜 an origin line: which people/region tell it, the oldest known source, and a note that versions differ → 📚 sources → 🎬 an "Original animated short — a retelling of a traditional legend" note → 🎙️ "Voiceover generated with ElevenLabs." → 3–4 hashtags.

**Short caption (Shorts / TikTok / Reels)**: one line with the hook and the payoff, plus an emoji and 4–5 hashtags.

**YouTube tags**: 20–28 comma-separated tags. Cover:
- the myth's name and its characters (e.g. alamat ng pinya, Pina, Bakunawa)
- "legend of X", "myth of X", "origin of X", "alamat ng X"
- the culture/region (Filipino mythology, Philippine folklore, Visayan legend, Greek mythology…)
- the key objects or creatures
- genre tags: animated myths, cartoon mythology, mythology shorts, folklore, legends, bedtime stories, fun facts, did you know, educational animation
- the theme, e.g. origin stories, cursed love, trickster tales

**Hashtags (TikTok / Reels)**: 12–15 hashtags, e.g. #mythology #folklore #legend #alamat #<myth> #<culture>mythology #philippinemythology #myths #storytime #animation #cartoon #shorts #edutok #learnontiktok

**Upload tips** (one short paragraph in Tagalog):
- "Not made for kids" unless the user is sure of the audience (scary creatures may also need care).
- Turn on "Altered or synthetic content" (AI voice).
- Free ElevenLabs plan: no commercial use; keep the attribution.
